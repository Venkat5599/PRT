Run it

cargo build --release
canary doctor   --ws wss://mainnet.portaldot.io
canary upgrade  --ws ws://127.0.0.1:9945 --wasm runtimes/out/ed100x.compact.wasm
canary test     --baseline ws://127.0.0.1:9944 --candidate ws://127.0.0.1:9945
canary reproduce balances.transfer.basic --run runs/<id>

Exit 0 on pass or difference, 1 on regression, 2 when inconclusive. Also a GitHub Action: uses: Venkat5599/PRT@main.
